# C — Scoreboard
1. Reps are competitors, so the dashboard opens on a broadcast score bug: estimated pay and weekly rank side by side, same size, one read.
2. Every number that matters is set in Bebas Neue (the marketing site's display face, already loaded) with tabular figures; all words are Geist at 12px or larger, so the numerals do the shouting and the copy stays calm.
3. One surface language: near-black ground, one panel tone, 1px hairlines, 8px/6px/4px radii. Lime means "yours / earned" (rank, progress, primary action); amber means "needs you" (install date, Check this). Nothing else gets colour.
4. Progress is shown as bars, never as paragraphs: the pay period is a 10-segment stack (installed / scheduled / needs date), the challenge is 10 ticks, the Log Sale flow is a two-step meter that fills as fields are read and confirmed.
5. Log Sale is screenshot-first with proof kept in view: the scan panel is the whole first screen, the review puts the screenshot beside the form (desktop) or pinned above it (phone) so every flagged field can be checked against the source.
