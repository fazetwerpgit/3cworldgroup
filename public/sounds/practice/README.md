# Practice sounds

Door and background sounds for Ask 3C Practice (Talk on only). Every clip is
public domain (CC0 1.0): free to use, change and ship, commercially, with no
attribution required. Sources and licenses were checked on each clip's own page
on 2026-09-28. All clips are mono MP3 at 22.05 kHz, cut and re-encoded from the
originals: one-shots are peak-normalized to -3 dB at 48 kb/s. The `bed-*` loops
are loudness-normalized, low-passed (heard through the open door), cross-faded
into seamless loops, and encoded at 32 kb/s. The whole set is about 255 KB, and
the page loads a clip only when it's first played.
